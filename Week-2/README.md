# Week 2. Data Collection, Cleaning and Preprocessing

## Objective

This week the task is to prepare logistics data for analysis and machine learning.

The main goal is to see how important data quality is and to build a preprocessing workflow with Python.

We want to learn how to make data clean and ready for any steps.

## Dataset

The project continues to use the E-Commerce Public Dataset by Olist.

The dataset contains information about:

- Orders

- Customers

- Sellers

- Products

- Freight

- Reviews

- Geographic information

## Work Completed

The preprocessing workflow covers:

- Data collection and understanding

- Data profiling

- Missing‑value analysis

- Duplicate detection

- Data type correction

- Outlier detection

- Outlier treatment

- Categorical data checking

- Feature engineering

- Data normalization

- Standardization

- data validation

## Python Libraries

The main libraries used are:

- Pandas

- NumPy

- Matplotlib

- Scikit‑learn

## Expected Outcome

The final goal is to build a cleaner more reliable dataset that can be used for exploration, prediction, clustering and improvement work later in the project.

We aim to have data that's ready, for any analysis or model you want to build.
