# Week 1. Strategic Planning and Data Exploration in Logistics

## Project

Strategic Planning and Data Exploration in Logistics

## Objective

The aim of this week is to see how data science can help with a logistics problem. The project looks at delivery performance. We want to spot delivery delays understand transportation costs and find ways to make logistics operations better.

## Logistics Scenario

The project looks at an e‑commerce logistics operation where sellers deliver orders to customers. The main challenge is to balance delivery speed, customer satisfaction, transportation cost and available logistics capacity.

## Dataset

The project uses the E-Commerce Public Dataset by Olist.

The dataset contains information about:

- Orders

- Customers

- Sellers

- Products

- Freight

- Payments

- Reviews

- locations

## Key Performance Indicators

The main KPIs considered are:

1. On‑Time Delivery Rate

2. Average Delivery Lead Time

3. Late Delivery Rate

4. Average Freight Cost per Order

5. Freight‑to‑Order Value Ratio

6. Average Customer Review Score

## Data Science Techniques

The following techniques are planned:

- Exploratory Data Analysis

- Regression

- Classification

- Clustering

- Optimization

## Planned Workflow

1. Data collection

2. Data integration

3. Data cleaning

4. Feature engineering

5. Exploratory data analysis

6. KPI calculation

7. Predictive modeling

8. Clustering

9. Optimization

10. Business recommendations

## Expected Outcome

The goal is to find factors that cause delivery delays and high logistics costs. The analysis should give insights that help logistics teams improve delivery performance and resource allocation.
